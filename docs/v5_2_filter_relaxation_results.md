## 문제: RSI와 CVD의 논리적 충돌

```
LONG 시그널 → CVD < Q25 (투매 바닥) 필요
            → 그런데 RSI > 50 도 필요
            → 투매가 나오면 RSI가 50 밑으로 떨어짐
            → 완벽한 진입점에서 RSI가 차단
```

## 분석

### Sharpe vs 거래 빈도 트레이드오프

```
RSI 50 + Q75:  92건, Sharpe 4.88  ← 현재 (최고 Sharpe)
RSI 45 + Q75: 124건, Sharpe 4.67  ← +35% 거래, Sharpe -0.21
RSI 40 + Q75: 139건, Sharpe 4.47  ← +51% 거래, Sharpe -0.41
RSI 35 + Q75: 148건, Sharpe 3.92  ← +61% 거래, Sharpe -0.96
```

### CVD 완화 효과

```
Q75: 92건, Sharpe 4.88  ← 최적
Q70: 117건, Sharpe 3.96  ← -0.92 (급락)
Q65: 135건, Sharpe 3.73  ← -1.15 (더 악화)
```

CVD를 Q75에서 Q70으로 바꾸면 Sharpe가 0.92 떨어짐 → **CVD Q75는 건드리면 안 됨.**

### RSI 완화는 소폭 유효

RSI 45(±5 완화)로 바꾸면:
- 거래 +35% (92→124건)
- Sharpe -0.21 (4.88→4.67, 여전히 높음)
- WR -5%p (64→59%, 여전히 양호)

## 결론

| 옵션 | 거래 증가 | Sharpe 변화 | 판정 |
|------|----------|------------|------|
| **현재 유지 (RSI50+Q75+kl2.0)** | — | 4.88 | **최고 품질** |
| RSI 45로 완화 | +35% | 4.67 (-0.21) | **거래 빈도 필요시 차선** |
| CVD Q70으로 완화 | +27% | 3.96 (-0.92) | 불채택 |
| RSI 40 + CVD Q75 | +51% | 4.47 (-0.41) | 공격적 옵션 |

**현재 config (RSI50+Q75+kl2.0)이 Sharpe 최적.** 거래 빈도가 부족하다고 느껴지면 RSI를 45로 완화하는 것이 유일한 합리적 선택.
