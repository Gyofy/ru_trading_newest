## 불채택 사유

- **Scale-out**: MDD 최저(-10.7%)이지만 avg PnL -0.23%p 하락
- **Smart TTL**: 연장 시 추세 약화로 오히려 수익 감소
- **Signal exit**: 거래 많아지나 조기 청산으로 per-trade PnL 하락
- **Full combo**: 복잡도 대비 개선 없음
- **상관관계 필터**: 단일 코인 테스트에서 효과 측정 불가
