```
전략 A: 상승장(28d>0)에서 LONG만
전략 B: 하락장(28d<0)에서 SHORT만
횡보:   FLAT (거래 안 함)
```

## 전략 로직

```
매 4h bar:
  1. 28d return 확인 → 레짐 판단
     > 0: UPTREND → LONG만 허용
     < 0: DOWNTREND → SHORT만 허용

  2. 7d TSMOM → 방향 확인 (레짐과 일치해야)

  3. RSI > 50 (LONG) / RSI < 50 (SHORT)

  4. CVD Q75 극단 → 진입 타이밍

  5. OI |z| < 2.0 → 과열 체크

  6. 진입: TP=5×ATR, SL=2×ATR, TTL=24bars
     레버리지: 2x 고정
```

## 왜 이게 작동하는가

1. **LONG은 어떤 구간에서든 약간 양수** (IS +0.29%, OOS +0.44%)
   → CVD 투매 바닥 진입이 방향 무관하게 약간의 edge 제공

2. **SHORT은 하락장에서만 폭발** (OOS +4.49%, IS -0.66%)
   → 하락장이 아닐 때 SHORT을 차단하면 IS 손실 제거

3. **레짐 게이트 = 나쁜 SHORT 제거**
   → IS에서 마이너스였던 SHORT 100건 중 상승장 SHORT만 제거
   → 남은 거래가 전부 양수 or 약손실

## 2x 레버리지 근거

```
IS per-trade-S: +0.072 (약하지만 양수)
2x 적용 시: per-trade-S ≈ +0.072 (레버리지는 Sharpe 변경 안 함)
            avg PnL ≈ +0.86% × 2 = +1.72% (단, 비용도 2x)
            실질: ~+0.43% × 2 = +0.86%

→ 2x는 edge를 증폭하되 파산 위험 낮음
→ 3x 이상은 IS MDD(-56%)가 위험
```
