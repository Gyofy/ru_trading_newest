## 3. 브레인스토밍 Round 2 — 구조적 원인 탐구

### Round 1 반론

**반론 2-A: min_hold는 가짜 해결책**
5봉 이하 59건의 실패 원인은 **보유 시간이 아니라 진입 방향 자체가 틀림**.
MFE=0인 34건 = 진입 즉시 역방향. 더 오래 버티면 손실만 확대.

**반론 2-B: NY 세션 회피는 샘플 편향**
Asia 7건의 57.1% TP율은 95% CI가 18~90%로 통계적 무의미.
NY 거래가 많은 이유는 세션 탓이 아니라 전략 트리거 빈도 차이일 수 있음.

**반론 2-C: 전략 집중만으로 TP율 상승 보장 없음**
liquidation_fade BEP=47.8%에서 현재 36% TP율 → 흑자 전환 조건 미달.
"어떻게 TP율을 48%+로 올릴 것인가"가 진짜 질문.

### 구조적 원인 3가지

**원인 2-1: RR=1.5 수준은 수수료 극복 불충분**
```
liquidation_fade: avg RR = 0.578% / 0.385% = 1.50
BEP 공식: 수수료 / (TP거리 + 수수료) = 0.18% / (0.578% + 0.18%) = 23.7%?
→ 실제 BEP 47.8%가 나오는 건 슬리피지/스프레드 추가 비용 때문
```
진입 Taker 0.05% + 청산 Taker 0.05% + 슬리피지 0.04%×2 = 0.18%
**총 진입 핸디캡: 레버리지 4배 기준 원금의 0.72%**

**원인 2-2: MFE=0 34건 = 진입 품질 불량 28%**

| 전략 | MFE=0 건수 | 전체 대비 |
|------|-----------|---------|
| cvd_spike | 19 | 28.8% |
| asymmetric_sniper | 9 | 37.5% |
| liquidation_fade | 5 | 20.0% |
| momentum_breakout | 1 | 14.3% |

진입 즉시 역방향 = 신호 자체가 노이즈이거나, 추세 종료 직후 진입.
진입 전 1봉 방향 확인(Micro-Confirmation) 미비.

**원인 2-3: 수수료 0.18%가 실질적 진입 핸디캡**
```
4배 레버리지, 0.18% 수수료 → 원금 0.72% 핸디캡으로 시작
SOL 15분봉 ATR ≈ 0.3~0.5% 기준:
  수익 진입 = 최소 1.5~2.4 ATR 방향 이동 선행 필요
```

### Round 2 결론
문제의 핵심은 **진입 품질(MFE=0 28%)** 과 **수수료 대비 RR 구조** 두 가지.
소극적 접근(거래 감소)으로는 구조적 해결 불가.

## 4. 브레인스토밍 Round 3 — 리스크를 높여 수수료 벽 돌파

### 통합 핵심 관찰
- Round 1+2 모두 RR 구조를 건드리지 않음
- **수수료 0.18% 극복 = ① RR 대폭 확대 OR ② 수수료 구조 변경**
- liquidation_fade의 MFE 0.634% > TP 0.578% → **이미 TP 이상 움직임 발생 중**

### 가설 3-A: TP 청산을 Maker 지정가로 전환 ← **최우선 레버**

```
현재 구조 (Taker 청산):
  진입 Taker: +0.05%
  청산 Taker: +0.05%
  슬리피지:   +0.08%
  합계:        0.18%  → BEP 47.8%

Maker 청산 전환 시:
  진입 Taker: +0.05%
  청산 Maker: -0.02% (리베이트)
  슬리피지:   +0.04% (진입만)
  합계:        0.07%  → BEP 계산:
```

**BEP = 0.07% / (0.578% + 0.07%) ≈ 10.8%**

현재 liquidation_fade TP율 36% → BEP 10.8%를 이미 대폭 초과.
**이론상 즉시 흑자 전환 가능.**

- 구현: TP 주문을 market → limit으로 전환, SL만 market order 유지
- 리스크: TP 가격 도달 시 체결 안 될 수 있음 (지정가 미체결)
- 완화: TP 가격에서 0.01% 안쪽에 limit 설정 (aggressive limit)

### 가설 3-B: 1봉 Micro-Confirmation 필터로 MFE=0 제거

```
현재: 신호 발생 즉시 진입
제안: 신호 발생 후 다음 봉 확인 → 방향 일치 시 진입

예상 효과:
  MFE=0 34건 중 절반(17건) 필터링 성공 시
  → 수수료 절감: 17건 × avg 수수료 $8.3 = $141 절감
  → TP율 소폭 개선 (신호 품질 향상)
```

- 구현: 각 전략의 `evaluate()` 에서 신호 emit 후 다음 봉 open 방향 확인 조건 추가
- 리스크: 좋은 신호의 진입가 악화 (1봉 늦어지면 가격 불리)
- 적용 대상: cvd_spike, asymmetric_sniper (MFE=0 비율 높은 전략)

### 가설 3-C: liquidation_fade 단독 집중 + allocation 3배

```
현재:
  liquidation_fade: $4,500 allocation, 5× leverage, max_pos=10
  cvd_spike:        $9,000 allocation (TP 0%, 자원 낭비)
  asymmetric_sniper:$9,000 allocation (TP 0%, 자원 낭비)

제안:
  cvd_spike, asymmetric_sniper, momentum_breakout → disabled
  liquidation_fade: $18,000+ allocation, 단독 운용

예상 효과:
  거래당 notional 증가 → 동일 TP율에서 절대 수익 3배
  단, 동시 포지션 max_pos 조정 필요
```
