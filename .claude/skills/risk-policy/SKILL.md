# risk-policy

user-invocable: false

## 포지션 한도
- 종목당 최대: 계좌 순자산의 5%
- 섹터당 최대: 계좌 순자산의 15%
- 총 노출: 계좌 순자산의 80%

## 손실 한도
- 종목당 손절: 진입가 대비 -3%
- 당일 최대 손실: 계좌 순자산의 2% → 초과 시 전체 거래 중단
- 주간 최대 손실: 계좌 순자산의 5% → 초과 시 1영업일 거래 중단

## 데이터 품질 차단
- 최종 데이터 수신 후 5분 이상 경과 → 신규 주문 차단
- stale_flag=true인 종목 → 해당 종목 주문 차단
- 정제 파이프라인 미완료 → 전체 주문 차단

## 운영 모드
- `paper`: 모의 주문만 실행, 실제 API 호출 없음
- `live`: 실제 KIS API 주문 실행
- paper→live 전환 조건: 최소 20영업일 paper 운영 + Sharpe > 0.5 + MDD < 5%

## 주문 전 필수 체크 (pre-order gate)
1. 장 시간 내인가
2. 데이터 최신성 5분 이내인가
3. 포지션 한도 이내인가
4. 당일 손실 한도 이내인가
5. 모델 예측의 불확실성이 허용 범위인가
6. 유동성(호가 스프레드) 기준 통과하는가
